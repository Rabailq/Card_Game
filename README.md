# Card_Game
A Python-based two‑player card game featuring jokers, special rules, card swapping, WAR battles, and save/load functionality. Two players draw cards each round, earn points, trigger special effects, and compete until the round limit is reached.
The game can be saved at any time and resumed later.

How it works? 
- Fully shuffled 54‑card deck (includes 2 jokers)
- Cards dealt evenly between both players
- Round‑based system
- Automatic score tracking
- Game ends when round limit is reached or cards run out

Special rules in place: 
- Joker → Player loses 1 point
- King → Player gains 1 bonus point
- Queen → Both players swap all remaining cards
- Equal rank cards → WAR!
Each player places one card face-down
Next card decides the winner
Winner earns +2 points
